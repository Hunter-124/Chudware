# chudware-silent-dropped-key-audit

In an isolated workspace and daemon-off or private engine, build a fresh document for every case. Compare a canonical explicit control, an alias/input under audit, the default with the key omitted, and meaningful alternate and zero values. Assert measurable geometry, dimensions, volume or tree state; `ok:true` alone does not prove the key had an effect.

Inspect `services/mcp/cad_doc_tools.py` normalization and the engine consumer. Preserve canonical-key precedence, avoid guessing ambiguous intent, and reject unsupported keys clearly where appropriate. Cover both MCP and direct engine paths when the latter can bypass normalization. Use an explicitly selected build path.

Verify: `scripts/testbox.py --suite geom,sketch`
