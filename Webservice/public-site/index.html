A session in the browser

What is actually in a session

The browser runs the real UI; the geometry kernel runs server-side against your project data. Everything below is the same code as the desktop build.

  1. Parametric modeling

    Sketches, constraints and a feature history you can go back and edit. Parts and assemblies, driven by the OpenCascade kernel.

  2. An AI copilot that builds features

    Describe a part in plain language and the copilot creates real parametric features in the tree — not a mesh, not a one-shot export. You keep editing them by hand afterwards.

  3. PLM projects

    Versioned project vaults with history, so a team works against one source of truth instead of passing files around.

  4. Parts library

    A catalog of reusable components to drop into assemblies rather than re-modeling standard hardware each time.

  5. CAM, ECAD, simulation and drawings

    Dedicated workspaces for toolpaths, board work, analysis and 2D drawing output, in the same document as the model.

  6. A desktop build of the same application

    When you would rather use local hardware, the same application runs natively on Windows and Linux against the same project data.
