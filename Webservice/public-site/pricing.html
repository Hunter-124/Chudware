Pricing

You are paying for machine time, not for features.

Every tier is the same application. What changes is how much CPU and GPU session time you get, whether your work survives the end of a session, and how many copilot tokens are included.

What the price is actually made of

Chudware sessions are not cheap to run, and pretending otherwise would just produce a pricing page that has to change later. These are the four things that cost money.

  • CPU seat time

    A default seat renders and encodes in software on shared host CPU. It is the floor cost of having a session open at all, which is why the free tier does not keep one warm.

  • GPU seat time

    Accelerated seats get a slice of a GPU for rendering and hardware video encode. There are only so many at once, so they are metered and prioritised rather than unlimited.

  • Copilot tokens

    The AI copilot calls a language model, and that is billed per token upstream. Included allowances differ by tier; heavy use is metered instead of throttled silently.

  • Persistent storage

    A home directory that survives disconnects, plus project vault history, is real disk that has to be kept and backed up. The evaluation tier skips it entirely.
