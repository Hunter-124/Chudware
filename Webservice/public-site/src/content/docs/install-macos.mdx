## Choose the correct build

In **Apple menu → About This Mac**, check whether the processor is Apple silicon or Intel. Download the matching package from the [download page](/download/).

## Verify the download

In Terminal, run `shasum -a 256` followed by a space, drag the downloaded file into the Terminal window, and press Return. Compare the result with the release manifest.

## Open an unsigned build

Because current builds are unsigned and not notarized, macOS may quarantine the app. First try Control-clicking Chudware and choosing **Open**. If macOS still blocks it, open **System Settings → Privacy & Security**, confirm the downloaded filename and checksum, and choose **Open Anyway**.

Never remove quarantine from a file whose checksum does not match the published value.
