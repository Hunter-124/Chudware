## Use the browser workspace

Chudware does not currently publish a native macOS package. [Create an account](https://app.chudware.com/signup) and use the browser-streamed workspace instead; there is no desktop installer or checksum to verify.

Do not download an unofficial package or bypass macOS quarantine for a file presented as Chudware.

## Native previews

Native preview builds currently exist for Windows and Linux and are available on request from the [access page](/download/).
