## Native access is on request

The Windows desktop build is not yet published through a public release channel. Use the [access page](/download/) to request the Windows preview; there is no public installer or checksum to download today.

Do not install a package presented as an official Chudware release from a third-party source.

## Use the browser now

The browser client requires no desktop installation. [Create an account](https://app.chudware.com/signup) to use Chudware from a Windows browser while native distribution is being prepared.
