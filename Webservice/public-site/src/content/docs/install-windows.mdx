## Download the installer

Sign in at [app.chudware.com](https://app.chudware.com/#downloads) and open the download page. It issues the signed Windows installer (`.exe`) for your account, with the version and SHA-256 digest shown next to the link.

Run the installer and launch Chudware from the Start menu. Updates are verified against the same signed release manifests, so keeping the app current needs no manual downloads.

The build is 64-bit and needs a graphics driver capable of a modern hardware-accelerated 3D context; without one the application does not start.

Do not install a package presented as an official Chudware release from a third-party source; the download page in your account is the only official source.

## Or skip the install

The browser client requires no desktop installation. [Create an account](https://app.chudware.com/signup) to use Chudware from a tab.
