### Aggregator fix (paid filter)

`tools/flywheel/bench/gym/leaderboard.py` previously only treated `openrouter:` real cells as paid; real `xai:` cells were dropped. Filter now accepts both:

```python
has_real_paid_cell = any(
    (tier.startswith("openrouter:") or tier.startswith("xai:"))
    and cycle in real_cycle_names
    for cell in mcells
)
```
