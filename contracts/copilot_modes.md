# Copilot modes — Agent|Plan|Swarm|Edit|Ask tool gating (aicad.copilot_modes/1)

Status: FROZEN (v1, 2026-07-22). Machine-readable data: `contracts/copilot_modes.json` — both runtimes load THAT file at runtime (resolution order in its `notes`); neither runtime may keep a private copy of these sets. Consumers: `services/agent/copilot_mode_tools.py` (Python, gates `agent_turn.run_turn` for the MCP/DAG path) and `core/agent/copilot_modes.cpp` (C++, gates the in-app run loop in `core/agent/run.cpp`, e.g. the `delegate` mode gate).

Semantics (both runtimes implement exactly this): the mode vocabulary is `agent|plan|swarm|edit|ask`; an absent/empty/unknown mode normalizes to `agent`. `agent` and `swarm` are **unrestricted at the mode layer** (`tools_for_mode` → `null`; a role-card allowlist still applies, and swarm unions `swarm_extra_tools` onto a role card so corporate/delegate tools survive the intersection). The restricted modes compute `allowed = (role_tools ∩ mode_set | mode_set when no role)`, then subtract the mode deny set (`mutating_tools` for **ask**; `mutating_tools` for **plan** — plan is agent-broad minus geometry/document commit mutators; `edit_denied` for **edit**), then UNION `shared_default_tools` as a floor so doc lifecycle (`new_part`/`save_part`/`close_part`/`import_part`/`export_part`), `advise`, `ask_user`, web research, and the meta-tools `enable_tools`/`list_tool_categories` never dead-end a restricted mode — the shared floor deliberately wins over the denylists (plan can still build/save a simple part; ask/edit keep `new_part`). `plan_only=true` forces plan semantics under any mode. `is_tool_allowed` is the point query over the same computation (empty tool name → deny; `null` allowlist → allow). Parity between the two runtimes is enforced by `core/tests/test_copilot_modes.cpp` and `services/agent/test_copilot_modes_parity.py`, which assert identical allow/deny verdicts over the same mode × tool matrix; any change to the sets or the rules lands in the JSON, both loaders, and both tests in the same commit.
