# Contract: ECAD Library — v1

> Symbol + footprint + 3D-model libraries. Native format is JSON (matches the doc model); we also
> **import** KiCad libraries (clean-room S-expr parsing — interop, not derivation; see
> `ECAD_PLAN §2.1` and the licenses ledger). No KiCad library *content* is vendored in the repo.

## 1. S-expression reader/writer — `services/ecad/library/sexpr.py`

A tiny, dependency-free tokenizer/parser: `parse(text) -> nested list/atom tree`,
`dumps(tree) -> text`. Atoms: bare symbols, quoted strings (with `\"` escapes), numbers. This is the
shared substrate for all KiCad parsers. **Clean-room**: implements the well-known S-expr grammar; no
KiCad code consulted or copied. **Test:** round-trip of representative `.kicad_sym`/`.kicad_mod`
snippets is structurally stable.

## 2. KiCad symbol import — `services/ecad/library/kicad_sym.py`

`load_kicad_sym(path) -> {libid: SymbolDef}`. Maps `(kicad_symbol_lib (symbol "R" ...))`:
- `(property "Reference" "R" ...)` → `reference_prefix`; `(property "Value" ...)`,
  `(property "Footprint" ...)` → defaults; arbitrary properties → `fields`.
- `(symbol "R_1_1" (pin passive line (at x y ang) (length l) (name "~") (number "1")))` →
  `Pin` (type/shape/pos/angle/length/name/number, `unit` from the `_u_` suffix).
- Body graphics (`rectangle`,`polyline`,`circle`,`arc`,`text`) → `SymbolDef.graphics`.
- Coordinate convention converted to our mm/+y-up. Multi-unit via `units_count`.

## 3. KiCad footprint import — `services/ecad/library/kicad_mod.py`

`load_kicad_mod(path) -> Footprint-def` and `load_pretty(dir) -> {fpid: def}`. Maps
`(footprint "R_0603" (layer "F.Cu") (pad "1" smd roundrect (at x y) (size w h) (layers ...)) ...)`:
- `pad` → `Pad` (number/shape/pos/angle/size/roundrect_ratio/type/layers/drill).
- `fp_line/fp_circle/fp_arc/fp_poly/fp_text` on silk/fab/courtyard → `Footprint.graphics`.
- `(model "path.step" (offset ..)(scale ..)(rotate ..))` → `model_3d` + transform.
- `(attr smd|through_hole|virtual)` → `attr`.

## 4. Native library — `services/ecad/library/native.py`

JSON files: `symbols/*.sym.json` (a `SymbolDef`), `footprints/*.fp.json` (a footprint def),
`models/` (STEP). A `library.json` index lists entries with keywords for search. Loader resolves a
`libid`/`fpid` across: native dirs → user-configured KiCad lib paths → embedded `lib_cache`.
`search(query) -> [hits]` ranks by keyword/name match (feeds the AI `ecad_find_part` tool).

## 5. Clean-room starter library — `library/starter/`

Generated by a script (like `assets/make_icons.py`), **all original geometry**:
- Symbols: `R, C, C_pol, L, D, LED, Zener, Q_NPN, Q_PNP, NMOS, PMOS, OPAMP_dual, NE555,
  Conn_2/3/4, Header_1xN, GND, VCC, +5V, +3V3, -5V, V_source, I_source, Switch`.
- Footprints: IPC-7351-nominal `R/C 0402/0603/0805/1206`, `SOIC-8/14`, `SOT-23`, `TO-92`,
  `DIP-8/14`, `2.54 headers 1xN/2xN`, `SMD/THT LED`, `D-SMA/SMB`. IPC geometry is a public
  dimensional standard (not copyrightable); models are simple proxies.
- Each symbol carries a `sim` mapping (R→R, NE555→subcircuit stub, OPAMP→OPAMP) so the starter set
  simulates out of the box.

**Test:** starter lib loads; every symbol validates against `sch_schema`; every footprint against
`pcb_schema`; the 555 + RC + op-amp fixtures resolve entirely from the starter lib.
