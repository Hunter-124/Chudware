# License compliance register

This register lists open licensing and compliance items: places where a component that Chudware
uses, fetches, or can download does not yet fully meet the policy in
[`licenses.md`](licenses.md), or where a redistribution obligation is not yet met. `licenses.md`
records each dependency's license and posture; this file records what remains to be done about the
exceptions. [`THIRD_PARTY_NOTICES.md`](../THIRD_PARTY_NOTICES.md) is the notice file for what is
distributed.

Each item states the component, why it matters when Chudware or a deployment of it is
redistributed or hosted (including the experimental self-hosted web application in `web/`), the
mitigation currently in place, and the action that closes it. Item numbers are stable identifiers
referenced from other documents; closed items are removed without renumbering. A change that
introduces a new exception adds an item here in the same change.
