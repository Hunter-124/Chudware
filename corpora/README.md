# corpora — consolidated test fixtures

Fixture collections for the C++ core, the host GUI, and the Python services and tools.
The former Python `engine_oracle/` differential leg no longer exists; nothing here is a
three-engine oracle comparison any more. Collections whose original runner was removed are
kept as reference data, marked below.

| Subdir | Purpose | Status / consumer |
|--------|---------|-------------------|
| [`platform_parity/`](platform_parity/) | 12 corpus documents (11 `aicad.part/1`, 1 `aicad.asm/1`): extrude, revolve, fillet, chamfer, booleans, swept loft, patterns, constrained sketch, assembly mates, Netgen FEA — for cross-platform engine parity | **Live** — core ctest `platform_parity` (`test_platform_parity`, corpus path `CHUDWARE_PLATFORM_PARITY_CORPUS`) |
| [`sw_fixtures/`](sw_fixtures/) | 12 SolidWorks `.SLDPRT` import fixtures | **Live** — `services/mcp/test_sw_feature_import.py` (override with `CHUDWARE_SW_FIXTURES`); authored by `services/mcp/sw_fixture_author.py` |

| [`gsl_dataset/`](gsl_dataset/README.md) | Synthetic GSL corpus with per-face feature labels | **Live, regenerable** — only `README.md` and `.gitignore` are committed; samples come from `tools/gsl_dataset_gen.py` and feed `tools/gsl_gnn/train_ranker.py` |

## Native SW fixture observation — 2026-10-04

The freshly built `core/build-linux/bin/sketch_cli` executed all 18 `sw_parity`
fixtures: **10 AGREE, 8 DIVERGE, 0 ERROR; runner exit 8**. Divergences were
F1a/F1b (redundancy), F2a (tangency/convergence), F3a/F3b/F3c (arc constraints
and degrees of freedom), F4c (degrees of freedom), and F6 (convergence/geometry).
The original expectations and dated oracle notes remain unchanged; these are
native-versus-recorded-expectation differences, not new SolidWorks observations
or proof that every difference is a native solver defect.

Reproduce with `CHUDWARE_SKETCH_CLI="$PWD/core/build-linux/bin/sketch_cli"
python3 corpora/sw_parity/_run_fixtures.py`. An explicitly missing binary exits 2
before reporting any fixture solve. Do not baseline away divergences to obtain
a green cleanup report.
