# AI-CAD — AI Icon Regeneration Prompts

Ready-to-use image-generation prompts for **all 189** AI-CAD icons, so you can regenerate the full icon set with Gemini / Imagen. AI-CAD is a professional **parametric CAD program** (OpenCASCADE B-rep kernel, desktop engineering app); every prompt is written with that context so the model renders recognizable CAD geometry.

## How to generate

1. **Model:** `gemini-3.1-flash-image` (the current Gemini Flash image model) or `imagen-4.0-generate-001`. The free-tier key shipped in the repo has **no image quota** (Gemini image -> HTTP 429; Imagen -> "paid plans only"), so use a key with image generation enabled.
2. **Output:** save each PNG to `host/assets/icons/src/` with the **exact** filename shown (e.g. `extrude_boss.png`). The atlas compositor keys strictly off these names.
3. **Format:** **1024x1024 PNG, square, transparent alpha**, single centered subject with ~12% padding. No text, watermark, background card, or UI frame.
4. **Consistency tip:** generate one icon first as a *style anchor*, then pass it back as a reference image for the rest so all 189 read as one cohesive family. Keep camera and lighting constant.
5. When the PNGs are in `src/`, the compositor rebuilds `atlas_dark.png` / `atlas_light.png` / `atlas.json` (no C++ changes needed - the loader is unchanged).

> Two style kinds are baked into every prompt below: **render** = a small 3D CAD-feature preview; **icon** = a sleek modern UI glyph. A machine-readable copy lives in `host/assets/icons/icon_prompts.json`.
