## Highlights

- Chudware's own code is covered by the MIT License; third-party components retain their licenses and notices.
- Account-based licensing and software fees have been removed. Desktop use and source builds do not require a Chudware license key.
- The MIT source repository is public and can be cloned without an access request. No public desktop installer release is available. Existing runtime or beta prereleases must not be presented as a general desktop download.
- The desktop updater verifies signed update manifests and update payload signatures; that mechanism does not make unpublished installers available.
- AI is optional. Desktop Copilot requires its configured compatible runtime and your own supported provider account or API key.

## Getting started

Clone the [public repository](https://github.com/Hunter-124/Chudware) and follow its [Building from source](https://github.com/Hunter-124/Chudware#building-from-source) section; the issue tracker and contributing guide are there too. Supported desktop SDK and native runtime dependencies are pinned release assets in this same repository; the macOS ARM64 native runtime remains unpinned. See the [setup page](/download/) for current desktop availability.

## AI provider setup

- Configure desktop provider credentials only in **Settings → Providers**, never in chat or project files. Your provider's charges and privacy terms apply; Chudware does not sell AI tokens.
