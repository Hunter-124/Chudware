## Highlights

- The complete Chudware source code is public on [GitHub](https://github.com/Hunter-124/Chudware) under the MIT License.
- Accounts, sign-in, and license checks are gone. The desktop app runs fully without an account.
- Desktop builds for Windows, Linux, and macOS are published on [GitHub Releases](https://github.com/Hunter-124/Chudware/releases/latest).
- The in-app updater reads a signed update manifest from the latest GitHub release and verifies the update's Ed25519 signature before staging it.
- The [Chudcode](https://github.com/Hunter-124/chudcode) agent runtime behind the copilot is public too, and the app fetches it from its GitHub releases.

## Getting started

The [download page](/download/) explains which release file to pick for each platform. To build Chudware yourself, follow [Building from source](https://github.com/Hunter-124/Chudware#building-from-source) in the README.

Bug reports and feature requests go to [GitHub issues](https://github.com/Hunter-124/Chudware/issues). Read the [contributing guide](https://github.com/Hunter-124/Chudware/blob/HEAD/CONTRIBUTING.md) before sending a pull request.

## AI provider setup

- The copilot runs on your own supported AI provider account or API key, configured in **Settings → Providers**.
