## Get the current build

Open the [latest release on GitHub](https://github.com/Hunter-124/Chudware/releases/latest) and download the Linux x86-64 file that fits your system. No account is needed. GitHub shows a SHA-256 digest beside each asset; compare it with the output of `sha256sum` before you install.

## AppImage

The AppImage is one portable file with nothing to install. Mark it executable and run it:

```sh
chmod +x Chudware-*-linux-x86_64.AppImage
./Chudware-*-linux-x86_64.AppImage
```

## Distribution packages

On Debian and Ubuntu, install the `.deb` with apt:

```sh
sudo apt install ./chudware_*_amd64.deb
```

On Fedora and RHEL, install the `.rpm` with dnf (or zypper on openSUSE):

```sh
sudo dnf install ./chudware-*.x86_64.rpm
```

The `.tar.zst` archive runs on any distribution: unpack it and start Chudware from wherever you put it. Not every release carries every format; the release's asset list is authoritative.

## Requirements and updates

The build is 64-bit and needs a graphics driver capable of a modern hardware-accelerated 3D context; without one the application does not start.

Chudware checks GitHub for newer releases and verifies each update's Ed25519 signature before staging it. Only install Chudware from the project's GitHub releases or a build you made [from source](https://github.com/Hunter-124/Chudware#building-from-source).
