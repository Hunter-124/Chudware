## Get the current build

Sign in at [app.chudware.com](https://app.chudware.com/#downloads) and open the download page. It shows the published Linux x86-64 package, version, size, and SHA-256 digest for your account.

The current Linux build is an **AppImage**. Download it, mark it executable, and run it:

```sh
chmod +x Chudware-*.AppImage
./Chudware-*.AppImage
```

## Account-generated terminal command

The same page can generate a complete install command containing a personal, account-bound download token. The token expires after 15 minutes. Copy the ready-to-run command from the authenticated page rather than constructing one or sharing its token.

The build is 64-bit and needs a graphics driver capable of a modern hardware-accelerated 3D context; without one the application does not start.

Do not install a package presented as an official Chudware release from a third-party source; the download page in your account is the only official source.

## Or skip the install

The browser client requires no desktop installation. [Create an account](https://app.chudware.com/signup) to use Chudware from a tab.
