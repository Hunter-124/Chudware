## Current availability

For the browser deployment, follow [self-hosting from source](/docs/self-hosting/) on a Linux x86-64 host. It uses Docker Compose and has single-operator and browser AI limitations.

Public desktop installers are not yet available. Clone the [public MIT repository](https://github.com/Hunter-124/Chudware) and follow its [native build instructions](https://github.com/Hunter-124/Chudware#building-from-source). Supported desktop SDK and native runtime dependencies use pinned release assets in this same repository. [Contact the project](/contact/) about optional paid hosting.

The formats below describe configured desktop packaging, not public downloads. When an official installer is published, compare its SHA-256 digest with `sha256sum` before installing it.

## AppImage

An AppImage is one portable file. For a trusted desktop release that actually includes it, mark that file executable and run it:

```sh
chmod +x Chudware-*-linux-x86_64.AppImage
./Chudware-*-linux-x86_64.AppImage
```

## Distribution packages

On Debian and Ubuntu, install the `.deb` with apt:

```sh
sudo apt install ./chudware_*_amd64.deb
```

On Fedora and RHEL, install the `.rpm` with dnf (or zypper on openSUSE):

```sh
sudo dnf install ./chudware-*.x86_64.rpm
```

Use only packages actually listed in an official desktop release. The current release workflow targets AppImage, DEB, and RPM; an archive produced by a local packaging script is not a published release.

## Requirements and updates

The build is 64-bit and needs a graphics driver capable of a modern hardware-accelerated 3D context; without one the application does not start.

The desktop updater verifies signed update manifests and each update's Ed25519 signature before staging it. This does not make unpublished builds available. Use a trusted source build or a verified official desktop release after publication; runtime-only prereleases are not desktop installers.
