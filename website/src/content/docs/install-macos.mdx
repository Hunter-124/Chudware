## Current availability

Public desktop installers are not yet available. Clone the [public MIT repository](https://github.com/Hunter-124/Chudware) and follow [Building from source](https://github.com/Hunter-124/Chudware#building-from-source) for native prerequisites, or use a Linux server for [experimental browser self-hosting](/docs/self-hosting/). The desktop SDK and supported macOS x86-64 native runtime use pinned release assets in this same repository; the macOS ARM64 native runtime remains unpinned. Source publication does not remove that ARM64 limitation. [Contact the project](/contact/) about optional paid hosting.

## Configured packaging target

The release configuration targets ARM64 for Apple silicon, with the filename convention `Chudware-<version>-macos-arm64.zip`. This is not a currently available download or an Intel-through-Rosetta release.

When an official macOS app is published, compare its SHA-256 digest with `shasum -a 256` before opening it, then unpack the archive and drag Chudware into Applications. Check that release's signing and notarization notes; do not bypass Gatekeeper for an untrusted or unverified build.

## Platform differences

The macOS build does not include the embedded browser used on Windows and Linux, so sign-in to AI providers and parts vendors opens in your system browser. See [macOS Parts Library vendor access](/docs/troubleshooting/#macos-parts-library-vendor-access) for how vendor searches behave on macOS.
