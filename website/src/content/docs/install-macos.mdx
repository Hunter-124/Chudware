## Download the app

Open the [latest release on GitHub](https://github.com/Hunter-124/Chudware/releases/latest) and download the macOS zip archive (`Chudware-<version>-macos-x86_64.zip`). No account is needed. GitHub shows a SHA-256 digest beside each asset; compare it with the output of `shasum -a 256` before you open the app.

Unpack the archive and drag Chudware into Applications. On Apple silicon the Intel build runs through Rosetta 2. A native Apple-silicon build is not published yet.

If a build is not yet signed and notarized with an Apple Developer ID, Gatekeeper warns on first launch. Only open a file you downloaded from the project's GitHub releases and whose digest you checked.

## Platform differences

The macOS build does not include the embedded browser used on Windows and Linux, so sign-in to AI providers and parts vendors opens in your system browser. See [macOS Parts Library vendor access](/docs/troubleshooting/#macos-parts-library-vendor-access) for how vendor searches behave on macOS.
