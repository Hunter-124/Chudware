## Download the app

Sign in at [app.chudware.com](https://app.chudware.com/#downloads) and open the download page. It issues the signed macOS zip archive for your account; unpack it and drag Chudware into Applications.

On Apple silicon the published Intel build runs through Rosetta 2. A native Apple-silicon build is not published yet.

Do not download an unofficial package or bypass macOS quarantine for a file presented as Chudware; the download page in your account is the only official source.

## Or skip the install

The browser client requires no desktop installation. [Create an account](https://app.chudware.com/signup) to use Chudware from a tab.
