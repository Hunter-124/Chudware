## Current availability

Public desktop installers are not yet available. Clone the [public MIT repository](https://github.com/Hunter-124/Chudware) and follow [Building from source](https://github.com/Hunter-124/Chudware#building-from-source) for a native build, or use a Linux server for [experimental browser self-hosting](/docs/self-hosting/). Supported desktop SDK and native runtime dependencies use pinned release assets in this same repository. See [setup choices](/download/) or [contact the project](/contact/) about optional paid hosting.

## Configured installer formats

The Windows packaging targets below describe filenames, not currently available downloads. When an official installer is published, verify its SHA-256 digest with `Get-FileHash` in PowerShell before running it.

- **Setup (`Chudware-Setup-<version>-x86_64.exe`)** is the interactive installer. Run it, then launch Chudware from the Start menu.
- **Installer (`Chudware-<version>-x86_64.msi`)** is for managed and scripted deployment through Group Policy, Intune, or `msiexec`.

The build is 64-bit and needs a GPU driver with hardware-accelerated 3D. Without one the app won't start.

## Updates

The desktop updater verifies signed update manifests and each update's Ed25519 signature before staging it. This does not make unpublished builds available. Use a trusted source build or a verified official desktop release after publication; runtime-only prereleases are not desktop installers.
