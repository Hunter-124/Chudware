## Download the current installer

Sign in at [app.chudware.com](https://app.chudware.com/#downloads) and open the download page. It shows the published Windows x86-64 build, version, size, and SHA-256 digest for your account.

The current Windows build is a signed **Setup (`.exe`)** installer. Download it, run the installer, and launch Chudware from the Start menu.

The build is 64-bit and needs a GPU driver with hardware-accelerated 3D. Without one the app won't start.

Do not install a package presented as an official Chudware release from a third-party source; the download page in your account is the only official source.

## Or skip the install

The browser client requires no desktop installation. [Create an account](https://app.chudware.com/signup) to use Chudware from a tab.
