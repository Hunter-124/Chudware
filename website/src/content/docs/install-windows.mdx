## Download the current installer

Open the [latest release on GitHub](https://github.com/Hunter-124/Chudware/releases/latest) and download the Windows x86-64 installer. No account is needed. GitHub shows a SHA-256 digest beside each asset; compare it with the output of `Get-FileHash` in PowerShell before you run the installer.

- **Setup (`Chudware-Setup-<version>-x86_64.exe`)** is the interactive installer. Run it, then launch Chudware from the Start menu.
- **Installer (`Chudware-<version>-x86_64.msi`)** is for managed and scripted deployment through Group Policy, Intune, or `msiexec`.

The build is 64-bit and needs a GPU driver with hardware-accelerated 3D. Without one the app won't start.

## Updates

Chudware checks GitHub for newer releases and verifies each update's Ed25519 signature before staging it. Only install Chudware from the project's GitHub releases or a build you made [from source](https://github.com/Hunter-124/Chudware#building-from-source).
