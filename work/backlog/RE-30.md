## Context
The RE workspace stepper currently implies a single photogrammetry flow
(Capture → Scale → Reconstruct → Model → Review → Deliver). But Reconstruct/Model must be
reachable from MULTIPLE source lanes, and doc-based sources must NOT be forced through
Scale/Reconstruct. Make the workspace source-driven.

**Source lanes (all converge at Model → Review → Deliver):**
- **Scan** (photos / webcam / video): Source → Scale → Reconstruct(mesh) → Model → Review → Deliver
- **Datasheet** (local PDF/spec): Source → (ingest) → Model → Review → Deliver  (skip Scale/Reconstruct)
- **Web / Part number** (search a part #, paste a listing/vendor URL, pull specs from the internet):
  Source → Research/Enrich (RE-29 `reveng_research_source`) → Model → Review → Deliver
- **From Parts Library**: seeded via `reveng_start_session(part_ref)` from an un-modeled part's
  photos/datasheets, then routed to Scan (if photos) or Datasheet/Web (if only docs/specs).

## Write-set
- `host/src/ui/reveng/reveng_workspace.cpp` + `reveng_internal.h` — source-mode selector (Scan /
  Datasheet / Web+Part# / From Parts Library) and an ADAPTIVE stepper whose stages depend on the
  chosen lane (doc lanes omit Scale + Reconstruct).
- `host/src/ui/reveng/sources_panel.{h,cpp}` (new) — the Sources entry UI: part-number/URL/query
  field wired to async `reveng_research_source` (RE-29), datasheet dropzone (reuse RE-15/img_tex),
  and the scan/webcam entry (RE-19).
