## Context
Hunter (2026-07-08): the Parts Library must let a user take a part that ships NO 3D model and, in one
click, pull standard/spec info from the internet and generate a 3D model for it (then place it in
assemblies). The backend one-call flow exists on master — `reveng_make_part_from_library(part_ref,
part_number?, query?)` (RE-33: seed→research→build→attach→placeable). This task adds the user-facing
entry point in the Parts Library UI and routes results into the RE workspace.

## Write-set
- `host/src/ui/parts/parts_browser_panel.cpp` (and/or `host/src/ui/parts/parts_workspace.cpp`) —
  additive right-click / row action on a metadata-only (no-model) part: "Reverse Engineer →
  Generate 3D model". Disabled/hidden for parts that already have a model. On click, async
  `st.rpc.call("reveng_make_part_from_library", {part_ref, part_number?})` (NEVER sync in draw
  paths), switch to the Reverse Eng workspace, and show the seeded session progressing through
  research→build. On success the part becomes placeable (RE-23 attach already handles the hub).
- Minimal additive hook in `host/src/ui/reveng/reveng_workspace.cpp` / `reveng_internal.h` at
  RE-ANCHOR to display the externally-seeded session (if not already handled by the session rail).
