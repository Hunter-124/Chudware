## Context
Hunter (2026-07-08): the Reverse-Engineering pipeline must be FULLY wired to the Parts Library so
that for a part which ships no 3D model, we can (a) pull standard/spec info from the internet and
(b) generate a 3D model for it, then place it in assemblies. The building blocks all exist and are
on master — this task composes them into ONE backend call so the GUI (RE-32) can trigger it with a
single click:
- `reveng_start_session(part_ref=...)` seeds a session from a parts-hub entry (RE-23)
- `reveng_research_source(session_id, part_number|query|url)` pulls datasheet+specs+images from the
  internet with provenance (RE-29)
- the `reveng_datasheet` mission builds a parametric part (RE-17); fit-critical dims still gate via
  `confirm_dimensions` (intake ledger)
- `reveng_attach_result(session_id, part_ref)` registers the model on the parts-hub entry so
  `part_place` works (RE-23)

## Write-set
- `services/mcp/reveng_tools.py` (additive at RE-ANCHOR) — `reveng_make_part_from_library(part_ref,
  part_number?, query?, auto_confirm_non_critical?=True)`: runs seed→research→build→attach and
  returns `{ok, session_id, part_ref, model_present, pending_dims?}`. When fit-critical dims are
  unresolved it returns them for the caller to confirm rather than guessing (honest gate), and
  leaves the session resumable. Offline/tools-absent → honest `{ok:false, reason, hint}`.
- `services/mcp/test_reveng_make_part.py` (new) — mocked research + mission runners.

## Acceptance
- `python3 -m pytest services/mcp/test_reveng_make_part.py -q` passes: a metadata-only part with a
  known MPN (e.g. a bearing) → `reveng_make_part_from_library` → parts-hub entry reports a model
  present and `part_place` succeeds (core RPC mocked). A part with unresolved fit-critical dims
  returns `pending_dims` and does NOT fabricate them. Offline → honest envelope.
- Existing `services/mcp/test_reveng_tools.py`, `test_reveng_parts_roundtrip.py`,
  `test_reveng_research_ingest.py`, `test_mcp_freshness.py` still pass.
