# RE-17 — DAG missions wiring (reveng orchestration keystone)

Fill `reveng_reconstruct` and `reveng_build_parametric` in
`services/mcp/reveng_tools.py` to launch the frozen DAG mission templates
(`services/dag/templates/reveng_{scan,datasheet}.json`) via
`services/dag/executor.py`, emitting `aicad.reveng_events/1` through the
EventJournal, honouring the `gate_before_exec` human gates (scale-confirm,
dimension-confirm), and degrading honestly (`backend_not_provisioned`) when
reconstruction backends are absent.

Additionally: add a `reveng_deviation` entry to
`services/dag/verify.py:DISPATCH_TABLE` mapping to `get_reveng_deviation`
(engine_oracle/vision/deviation.py), so the mission's mesh-vs-B-Rep verify node
actually runs instead of escalating `unknown_check_type`.

## Done

- `reveng_reconstruct` / `reveng_build_parametric` launch the `reveng_scan` DAG
  mission via `executor.run`, emit `aicad.reveng_events/1` on the run
  EventJournal, and pause at the scale/dimension approve gates
  (`autonomy_default="auto"` so only declared approve nodes gate; the human
  resumes via the DAG resume path). Backend absent → honest
  `backend_not_provisioned` envelope.
- `reveng_deviation` added to `verify.py:DISPATCH_TABLE`
  (`("reveng", "get_reveng_deviation", _check_reveng_deviation_default)`) plus a
  `reveng` branch in `_get_fn` and a `reveng_deviation` case in
  `_build_tool_kwargs`. The verify node now dispatches the deviation tool instead
  of escalating `unknown_check_type` (proven in `test_reveng_missions`).
- `services/dag/test_reveng_missions.py` walks `reveng_scan` with mocked node
  runners: asserts stage-event order, both gates pause+resume, and the verify
  dispatch. `services/dag/test_verify.py`'s exact-set dispatch test updated
  additively.
