## ANSWERS FOUND IN-SESSION (opus-ember, 2026-07-03) — Q1/Q2 no longer blocking

**Q1 RESOLVED — the feedback was NOT stale; it was a real loader bug, now FIXED.**
Root cause (host/src/ui/icons_sdf.cpp): the 8SSEDT sentinel `kFar = 1<<20` overflowed
`int` in `distSq()` ((2^20)^2 * 2 wraps int32 to 0/negative), so garbage sentinels WON the
min-compare, the distance field filled with negative values, `sqrt()` of them produced NaN,
and every SDF-qualifying glyph rasterized to alpha=0 — silently INVISIBLE. Exactly six atlas
glyphs qualify for the SDF path (chroma spread <= 40): `weld_gusset`, `display_hlr`,
`appr_metal`, `appr_glass`, `display_edges`, `view_cube` — i.e. precisely your "not showing"
list (+3 you didn't mention). Assets were healthy all along (opus-gleam's forensics were
right); the draw path ate them. Fixed with `kFar = 1<<12` (no overflow) — verified in-context:
Hidden Removed + material buttons now render in the Appearance ribbon, dark AND light.
Note: Weldments' ribbon renders EMPTY headless (contextual tab gating, pre-existing), so
weld_gusset is verified by shared root cause + asset health, not a ribbon screenshot.

**Q2 RESOLVED — hook added.** `CHUDWARE_RIBBON_TAB=<name>` (features|sketch|evaluate|simulation|
assembly|sheetmetal|weldments|pcb|surfaces|appearance|manufacture) now selects the tab in
`CHUDWARE_SHOT=ribbon` runs (host/src/app.cpp; alias over the numeric CHUDWARE_TAB). Also added
`CHUDWARE_HIDDEN=1` (shot-mode-only unmapped window) for compositor-independent headless runs.

**Q3 CONFIRMED by construction.** The pipeline renders through the app renderer's thumbnail
FBO (clean viewport: lit solids + feature edges, no gizmo/labels/UI) with a transparent
background — never `render_part`'s annotated debug image.

**NEW for round-2 review:** contact sheet of the generated photographic tiles is committed at
`work/questions/T-G15-contact-sheet.png` (transparent tiles on checkerboard).

**HEADS-UP for every GUI driver (cost us ~2h):** the HOST binary's headless flag is
`--ui-screenshot`, NOT `--shot` (that's AI-CAD2's flag). Passing `--shot` to host Chudware
falls through to INTERACTIVE mode — the scenario never arms and the app never exits, which
looks exactly like a hang. At least one other driver hit this today (an m1 run idled 90+ min).
