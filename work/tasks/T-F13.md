## Driver notes (Fable, 2026-07-02)

- **Features already engineered:** `tools/gsl_gnn/dataset.py:29-34` — 18-dim node
  features (surf one-hot(7), area/diag², log1p(radius), concavity one-hot(3),
  normal xyz, centroid/diag) + 2-dim edge features (convex flag, len/diag). The MLP
  ranker consumes per-candidate aggregates of these — reuse the dataset loader, do
  not re-extract.
- **Labels are free:** `tools/gsl_dataset_gen.py` samples carry `faces.json` with
  owner_feature_id ground truth; regen GO-family data with
  `python3 tools/gsl_dataset_gen.py --count 200 --families
  ribbed_bracket,shelled_enclosure,swept_pipe`. Family-stratified 80/20 split
  precedent in `tools/gsl_gnn/train.py:64-79`.
- **Candidate source:** the deterministic 5-pass recognizer behind
  `reverse_engineer` (`services/mcp/recon_tools.py`) emits ranked candidates;
  the hook point re-orders that list only. Score with `eval_compare`/match_pct
  (`compare_parts` at recon_tools.py:1119) exactly like `tools/gsl_eval.py` does
  (GO/NO-GO thresholds at gsl_eval.py:53-54).
- **Export for parity:** save weights as plain numpy/JSON and run inference in
  numpy — no torch dependency in the serving path (torch stays a training-only dep
  per tools/gsl_gnn/requirements.txt). Microseconds on CPU is the budget.
- **Hard contract:** ranker re-orders deterministically-generated candidates; it
  never emits geometry, numbers, or new hypotheses; flag default OFF; deterministic
  order is the fallback and the baseline it must beat.
