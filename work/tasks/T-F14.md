## Steps

1. Freeze the contract: each `make_*` takes a JSON spec (outline + slot references),
   returns an artifact record. Slots reference tool results (describe_*, FEA results,
   BOM rows) by id — the model composes structure and prose, code fills load-bearing
   numbers (provenance rule §3.3).
2. Wrap the engines; one smoke template per format (title-slide deck, one-page report,
   one-sheet workbook with a real formula).
3. `render_document(path)`: office→PDF via LibreOffice headless, PDF→PNG pages via
   pdfium; native paths for pdf/svg/png/csv/md. Returns downscaled preview images
   (≤1024px, resource_link to full file) so external MCP clients see previews too.
4. Artifact registry persists under the project dir; `list_artifacts` reads it.
5. Tests: subprocess-mocked converters + real in-process engines; a 4B-model-shaped
   spec fixture must produce a valid file for each format.

## Driver notes (Fable, 2026-07-02)

- **License table is the whole dependency decision — no judgment calls:** in-process
  = python-pptx, python-docx, openpyxl, matplotlib, reportlab/WeasyPrint, pypdfium2
  (pdfium, BSD). Subprocess-only = pandoc (GPL), LibreOffice headless (MPL). Never
  pymupdf4llm/PyMuPDF (AGPL). CI must not require pandoc/LibreOffice installed —
  discover on PATH, contract-shaped `{ok:false, reason:"converter_missing",
  hint:"install libreoffice"}` errors, subprocess-mocked tests.
- **Artifact registry:** persist under the project dir as JSON records
  `{artifact_id, kind, path, created_ts, run_id, source_refs[], spec_ref}` — this is
  what `describe_project` (T-F8) and the preview pane (T-F16) will read, and what
  T-H1 telemetry references. Keep the record schema in the contract.
- **Provenance rule mechanics (§3.3):** the spec JSON references slots by id, e.g.
  `{"slot":"max_stress","from":{"tool":"run_fea_static","key":"max_von_mises_mpa"}}`.
  The template engine resolves slots from attached tool results; a spec with a bare
  numeral in a load-bearing slot is a validation ERROR — that's the testable form of
  "the model never types a number".
- **Image caps:** previews follow the same ≤1024 px / <1 MB rule as everything else
  agent-facing, `resource_link` to the real file.
- **Scope fence:** one smoke template per format only — the real engineering
  templates (design-review deck, calc package, BOM workbook) are T-F15; the in-app
  preview pane is T-F16.
