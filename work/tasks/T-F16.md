## Context

Pillar 15 UI half: every agent-produced file shows up in the app as an artifact card
with a real preview — transparency for deliverables. The heavy lifting (format→PNG) is
T-F14's service-side `render_document`; this task is the presentation surface. READ
`docs/AI_TOOLING_MASTER_PLAN.md` §Pillar 15.

**GUI-placement rule:** implement the view-model in `ui/abstract/` (framework-agnostic
seam) and wire the host renderer minimally — the ui/imgui migration (T-G7 copilot/panels
wave) ports the same view-model, so don't gold-plate host-side rendering.
