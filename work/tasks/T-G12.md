## Context

Erik's directive (2026-07-02): AI-audited UI review isn't enough — a HUMAN must go
through the entire UI and give feedback on every single element/tool/option to get
something more refined. This task builds the checklist and captures the feedback; the
walkthrough itself is Erik's. The same checklist artifact is reused later for the new
ui/imgui shell (T-G9's sign-off requires it), so generate it from the app's own
definitions, not by hand.

**RECURSIVE, not one-shot (Erik, 2026-07-02, ratified):** the walkthrough is a LOOP —
walk the entire UI → annotate → fixes land → regenerate the inventory (the UI changed)
→ walk again — repeated until a full pass produces **zero new must-fix findings**
(convergence). Each round is cheap after the first because the kit and inventory script
already exist; the diff-vs-previous-round column shows Erik only what changed plus
anything he flagged last time. The GUI migration is NOT sign-off-complete (T-G9/T-G11)
until the walkthrough has converged — a round's must-fix findings block the sign-off,
recursively. T-G2's four NEEDS-LIVE click-tests seed round 1's checklist.

## Steps

1. Generate the inventory checklist; verify counts against the feature-surface audit
   so nothing is missed (every cmd_id accounted for).
2. Package a walkthrough kit for Erik: the checklist + how to launch each area fastest
   (scenario env vars, palette commands), with columns for keep/fix/kill + free-text.
3. HUMAN STEP: Erik walks the app, annotates every element.
4. Triage the annotations with Erik: convert accepted items into new task files
   (validate + regenerate DAG); wire must-fix items as deps of the relevant migration
   wave so the new UI never ports a rejected design.
5. LOOP: once that round's must-fix tasks are merged, regenerate the inventory against
   the updated app, produce a round-N+1 kit (diff-vs-previous highlighted, re-check
   items Erik flagged), and repeat steps 3-4. Converged = a full pass with zero new
   must-fix findings; record the converged pass explicitly in the final round file.
