## Context

Erik's T-G12 round-1 walkthrough (2026-07-03, `work/questions/T-G12-feedback-round1.md`).
Light mode looks really good; **dark mode is broken app-wide** — the single biggest
readability failure in the round. This is the P0 of the round-1 batch.

Findings:
1. **Every popup window breaks in dark mode**: black-on-black text.
2. **Property manager in the viewport (dark mode)**: the text background becomes
   black instead of the window background → black-on-black text in the fields; the
   window border also goes transparent in dark mode (correct in light mode). Strong
   smell of a theme token that maps text-bg → black instead of tracking the window-bg
   token when the palette flips.
3. **PM tool menus** (e.g. the 3D-body tools): formatting wrong — text overlapping
   UI controls; plus black-on-black text in dark mode.
4. **Copilot-tab tooltips**: black-on-black in dark mode.
5. **All subwindow OS borders are fully transparent** — fix (both modes).
6. **Evaluate tools** (Measure / Mass Props / Section Props, …) open at the wrong
   window size for the selected content — they should auto-scale to their content and
   carry the same liquid-glass effect as the tooltips/Copilot tab.

## Files / areas touched

- ui/imgui theme/palette definitions (dark-mode token table) — find via graphify
- PM form renderer (panel_spec-driven forms) — field text-bg + border styling
- Popup/subwindow chrome (border alpha, glass styling)
- Evaluate-tool result windows (auto-size-to-content)

## Steps

1. `graphify query "dark mode theme palette colors imgui"` and
   `graphify query "property manager panel form field background"` to locate the
   token tables before touching code.
2. Root-cause the dark-mode text-bg: likely one token (FrameBg/text-bg) resolved to
   near-black while text stays black. Fix at the token/theme level, NOT per-window
   overrides, so every popup inherits the fix.
3. Fix subwindow border alpha (transparent in both modes per Erik; at minimum broken
   in dark).
4. Fix PM tool-menu layout overlap (text vs controls) — likely fixed row heights vs
   font metrics.
5. Make evaluate result windows size to content + apply the shared glass style.
6. Verify BOTH modes: screenshot every popup/PM/tooltip surface in light AND dark
   (AI_CAD_SHOT scenarios are all unblocked since T-G13) and eyeball each PNG —
   no black-on-black anywhere. List the scenarios checked in the task log.
