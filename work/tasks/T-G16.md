## Context

Erik's T-G12 round-1 walkthrough (2026-07-03): the toolbar ribbon looks out of place
next to the rest of the program. Restyle it to the modern iOS-style liquid-glass
language already used by the tooltips and the Copilot tab — that's the reference
style, verbatim.

## Files / areas touched

- Ribbon rendering (ribbon_def-driven toolbar) — chrome, tab strip, group frames,
  button hover/active states
- Shared glass style helpers (reuse the tooltip/Copilot implementation — do not fork)

## Steps

1. `graphify query "ribbon toolbar rendering style"` and
   `graphify query "liquid glass tooltip copilot style helpers"` to find both the
   ribbon renderer and the canonical glass helpers.
2. Apply the glass treatment to the ribbon: background, tab headers, group separators,
   hover/pressed states. Keep hit-targets and layout metrics unchanged — this is a
   restyle, not a relayout.
3. Verify in BOTH light and dark mode (coordinate with T-G14's theme fixes; if T-G14
   hasn't merged, at minimum don't add new dark-mode regressions).
4. Screenshot every ribbon tab before/after for the round-2 kit.

## Verification (opus-gleam, 2026-07-03)

Changes (all in `host/src/ui/widgets/ribbon.cpp`):
1. Band: paint `ui::glassBackground(dl, wPos, wPos+wSize, 0.0f)` over the ribbon window
   (rounding 0 = full-width flush band; glass READ = translucent fill + inner shine +
   hairline border, same material as the tooltip glass). WindowBg base kept so
   `ribbon_chromeTint` stays referenced (no unused-static).
2. Tab pills: active/hovered tab now uses `ui::glassRowBackground(..., 4dp, selected=isAct)`
   — active tab gets the accent card, hover a frosted wash. Accent underline kept.
3. Button hover: big + small ribbon buttons swap the flat `buttonHovered` fill for
   `ui::glassRowBackground(..., 4dp)`. Armed-tool accentSoft+accent semantics kept.

Evidence: scratchpad `strip_base_dark.png` (before) vs `strip_g16_ribbon_dark.png`,
`strip_g16_ribbon_light.png`, `strip_g16_manu_dark.png` (after). Band + active-tab pill
verified in-image; button HOVER pills are only drawn on mouse-over (headless can't hover)
but use the SAME verified `glassRowBackground` helper as the visible active-tab pill.

Follows the SHARED VISUAL CONTRACT recorded in work/tasks/T-G15.md.
