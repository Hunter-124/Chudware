## Verification (opus-gleam, 2026-07-03)

Changes (all in `host/src/ui/widgets/ribbon.cpp`):
1. Band: WindowBg base made TRANSLUCENT (chrome-tint hue, alpha 0) — like the tooltip's
   transparent PopupBg — then `ui::glassBackground(dl, wPos, wPos+wSize, 0.0f)` painted over
   the ribbon window (rounding 0 = full-width flush band). The translucent base lets the
   glass fill + vertical inner-shine + top specular line + hairline border actually READ as
   the frosted material (an opaque base washed the effect out). `ribbon_chromeTint` stays
   referenced via the hue (no unused-static; confirmed no -Werror anyway).
2. Tab pills: active/hovered tab now uses `ui::glassRowBackground(..., 4dp, selected=isAct)`
   — active tab gets the accent card, hover a frosted wash. Accent underline kept.
3. Button hover: big + small ribbon buttons swap the flat `buttonHovered` fill for
   `ui::glassRowBackground(..., 4dp)`. Armed-tool accentSoft+accent semantics kept.

Evidence: scratchpad `strip_base_dark.png` (before, flat band) vs
`strip_g16b_dark.png` / `strip_g16b_light.png` (after — band now shows the frosted
vertical shine + top specular line + group separators, no viewport bleed). Active-tab
glass pill also verified (`strip_g16_manu_dark.png` — Manufacture tab). Button HOVER pills
are only drawn on mouse-over (headless can't hover) but use the SAME verified
`glassRowBackground` helper as the visible active-tab pill.

Follows the SHARED VISUAL CONTRACT recorded in work/tasks/T-G15.md.
