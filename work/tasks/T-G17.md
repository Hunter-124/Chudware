1. **Settings gear off-screen** — `drawCopilotHeader` right-side cluster
   (Sessions/Back toggle + gear + status dot) is now hard-anchored to the column's
   right edge and held off the very edge by a small inset, so the gear + dot are
   always fully on-screen and clickable at any width (they used to overflow past the
   right edge even at default width). The brand title yields gracefully:

   `drawProviderModelPicker` (default false). The in-tab AI Settings view calls it
   with `slim=true`, which drops the heavy "Manage models (chat picker)" bulk-toggle
   block; that block now renders ONLY in the Advanced settings window (Settings ▸ AI,
   `slim=false`). The composer's search dropdown is unchanged — it already is the slim
   quick picker for switching. See work/questions/T-G17.md Q1.
3. **Sessions popup + trashcan** — `drawSessionsPanel` reworked: each session is a
   glass row pill (matches the FeatureManager rows) with an accent card for the active
   session; the title is vertically centered; the trash button is a square box
   right-anchored WITH an inset (never clips) and vertically centered on the row.
4. **Sessions ↔ Back toggle** — the header's Sessions button becomes "< Chat" while
   the list is open (single toggle); the separate in-panel "Back to chat" button is
   removed.
5. **New-session full width** — `+ New session` now spans the whole tab width.
