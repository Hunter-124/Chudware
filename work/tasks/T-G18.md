## Implementation summary (opus-ridge)

**Row-style unification (host/src/ui/feature_tree.cpp).** The feature rows already had the
ratified look — a glass row pill + a shared accent-outline hover — while the meta/header rows
(filename, Equations, Material, Solid Bodies, Origin, default planes, mates, components, folders)
fell through to ImGui's default `HeaderHovered` paint, which is the "terrible" hover Erik flagged.
Fix:
- New `fmRowHoverPaint()` — the ONE approved hover treatment. The feature-row site and every
  meta row now call it, so hover is pixel-identical panel-wide (identical by construction).
- `fmRowPill()` now returns the pill rect and pushes the SAME `FramePadding` (row height/baseline
  parity) + transparent `HeaderHovered`/`HeaderActive` (kills the default hover); matching
  `fmRowPillEnd(rect, selected)` pops them and paints the shared hover. All 11 meta-row sites
  bracket with a Pill/End pair (stack-balanced).
- Dropped the plane rows' `ImGuiTreeNodeFlags_Selected` so selection shows via the glass card
  only (like feature rows), not an extra heavier `Header` paint.

**Icons (host/assets/make_icons.py — deterministic PIL pipeline; atlas re-packed).** Regenerated
`draw_undo`/`draw_redo` (bold single-tone circular arrows), `draw_equations` (clean Σ + equals),
`draw_material` (glossy accent swatch — placeholder until T-G15 screenshots), `draw_origin`
(RGB 3-axis gizmo). Transparent bg, dual-theme; verified against the packed atlas in both themes.
