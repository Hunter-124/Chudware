## Context

HUNTER (2026-07-03): the Feature Manager (left glass column) and Copilot (right
glass column) currently collapse **horizontally** (slide/shrink sideways, e.g. the
« button at the top of the FM). Change both to collapse **vertically** — the panel
rolls up toward the top of the viewport, leaving its header strip (with the
collapse button) in place. The collapse buttons themselves STAY at the top where
they are now; only the collapse direction/animation and the collapsed footprint
change.

Fits the locked overlay design intent (pinned glass columns over the full-width
viewport — gui-overlay-design-decisions): a vertically-collapsed column frees the
viewport underneath it while keeping the column's header pinned and discoverable.

## Implementation notes

**panel_collapse.h** — new shared `ui::PanelCollapseAnim` struct. Tracks animated
window height `h` with exponential approach (tau=0.12s), `measureHeader()` captures
the header strip height one frame after drawing, `bodyVisible()` gates body content
so a collapsed column costs nothing per frame. `snap()` sets `h` immediately for
deterministic headless captures.

**layout.cpp (drawLeftPane)** — FM collapse:
- Removed the old `if (s_collapsed) { pill... return; }` path and the ##LeftPanePill window
- `static bool s_collapsed = st.settings.fmCollapsed` (seeds from persisted setting)
- `s_anim.tick(s_collapsed, colH)` drives `winH` each frame; SetNextWindowSize uses `winH`
- Chevron toggle now bidirectional (`!s_collapsed`) and saves settings
- `s_anim.measureHeader()` called after the tab-row child; body wrapped in `if (s_anim.bodyVisible())`
- AI_CAD_FM_COLLAPSED env var + `s_anim.snap(true, colH)` for screenshot mode

**legacy_chat.cpp (drawAIPanel / drawCopilotHeader)** — Copilot collapse:
- Removed the old `if (s_cpCollapsed) { pill... return; }` path and ##CopilotPill window
- `s_cpInited` lazy-seeds `s_cpCollapsed` from `st.settings.copilotCollapsed`
- `s_cpAnim.tick` drives `winH`; conversation log + composer wrapped in `bodyVisible()`
- `s_cpAnim.measureHeader()` called right after the header separator
- AI_CAD_COPILOT_COLLAPSED env var + `s_cpAnim.snap(true, colH)` for screenshot mode

**app_state.h / app_state.cpp** — `Settings::fmCollapsed` / `Settings::copilotCollapsed`
added; serialized as "fm_collapsed" / "copilot_collapsed" in loadSettings/saveSettings.
