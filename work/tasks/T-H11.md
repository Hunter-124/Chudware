## Context

Pillar 16 / IP-18 — ranked the first NEW insertion point to migrate to a custom model
(`docs/CUSTOM_MODEL_INTEGRATION_SURVEY.md` §6). When a rebuild fails
(feature_status errors, dangling refs after topology-splitting edits), the model gets
the failure + doc context and returns a diagnosis + candidate fix ops. Ship
frontier-backed first, logged end-to-end via T-H7 middleware; every real failure→fix
becomes a correction trace. Verifier reward is binary and cheap: apply fix → rebuild
passes AND unaffected bodies compare ≈100% (compare_parts) — no silent intent changes.
Training data is unlimited: the T-H8 corruption corpus mutates known-good docs into
failures with known fixes. Migration gate (one quarter of logging): SFT (Qwen3-4B per
P13) on corruption corpus + harvested traces, GRPO with rebuild-passes reward; ship
only if within 5 points of frontier fix-rate on the frozen bench at <1/50th cost and
never below the deterministic-suggestion baseline (kill-switch rule). UX: diagnosis
renders as a fix-preview diff (T-H2 doc_diff) the user accepts/edits/rejects — which
is itself T-H1 telemetry.
