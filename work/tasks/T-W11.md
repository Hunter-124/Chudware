## Context

Pillar 20 capstone. Prove the thesis with numbers: the same mission ("bearing mount
bracket: Ø20 g6 shaft, sliding fit bore, 4x M5 base holes, aluminum, machined, FEA
sanity under 500 N side load") run (a) baseline loop, (b) advisory loop with roles,
on (1) a local 24k model and (2) sonnet-class. Metrics: iterations-to-converge,
check failures per stage, escalations, token spend, final verify_battery verdict.
This is the go/no-go evidence before deeper investment (and the Pillar 16 telemetry
pattern for advisory training data).

- `tools/flywheel/bench/benches/advisor_e2e.py` — new bench + mission spec fixtures
- `tools/flywheel/bench/` reporting — comparison table output (markdown)
- telemetry: advisory-shown → action → check-outcome triples logged via existing
  ai_artifact envelope (additive fields)

## Gaps this task found and fixed (the point of the spend)

1. **Tier dropped on the `enable_tools` tools-block re-render** (`agent_turn`) —
   `add_features` was delivering 335 of 11886 authored chars (2.8%) on exactly
   the turn a general-lane model first reaches modeling. 62 of 86 tool failures
   across 59 live user runs are that tool. Fixed + regression test.
2. **`verify_battery`'s FEA check graded nothing** (`services/verify/battery.py`)
   — scalars are nested under `summary`, the scan was top-level only, so it fell
   through to `1.0 if ok else 0.0`. A plate at min_fos 0.9944 (FAILING) scored a
   perfect 1.0. Fixed + 3 regression tests.
3. **A string dimension tolerance killed `ledger_render`** (`services/agent/ledger.py`)
   — `tolerance="g6"` (what a g6 mission naturally produces) raised
   `AttributeError: 'str' object has no attribute 'get'` and took down the
   advisory loop's whole state surface. Normalized at ingest + defensive render.
4. **Material dict keys were case-sensitive on one key** — `e_mpa` vs `E_mpa`
   told a model its correct 6061-T6 dict had a zero modulus.
5. **`set_process`/`dfm_check` never consulted the process alias table** — the
   mission says "machined"; both models were refused for `"machining"` while
   `_PROCESS_ALIASES` had known that word all along.
6. **Filed `T-BL61`**: a fillet inside `doc_apply_ops` SIGSEGVs hostd via OCCT
   `PerformFilletOnVertex` (coredump backtrace on the card). Not fixed — no
   deterministic reproducer yet, and `blend_drop_failing` structurally cannot
   contain a signal.
