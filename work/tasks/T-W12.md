## Context

Pillar 20 Part II (docs/ADVISOR_ARCHITECTURE.md §2.10, contracts/advisor.md §10 —
FROZEN). Hunter directive: every interface component gets checkers that ensure plans
will work BEFORE they touch the document. Planned ops dry-run on a shadow clone:
refs resolve, params sane, predicted rebuild status, downstream feature impact.
Freedom rule: a failed preflight never blocks — but overriding one without dispute
is a logged audit trigger.

## Steps

1. Read docs §2.10 + contract §10. Shape frozen.
2. Shadow clone: use the doc serialization round-trip (engine doc-load contract:
   doc_tree/doc_live_source → doc_new + apply) to build a THROWAWAY doc; apply the
   planned ops; capture feature_status, solver dof, doc_eval_check issues; discard.
   MUST be provably side-effect-free on the live doc (test asserts live doc revision
   and tree unchanged).
3. Check runners: refs_resolve (stable ids/names in ops exist in the clone),
   params_sane (positive dims; fillet/chamfer vs adjacent wall via doc_eval_measure;
   hole depth vs body extent), rebuild_predict (feature_status of the clone after
   apply), downstream_impact (walk the feature tree for features referencing edited
   faces/features — doc_adjacency + tree refs).
4. Emit aicad.preflight/1 with advisory_items ready for injection (severity mapping:
   fail→action, warn→hint; never blocker — freedom rule).
5. Wire: `preflight_ops` MCP tool (read risk class — it must never mutate); internal
   seam on add_features/set-param paths: run preflight, attach items, proceed
   regardless, log override event on fail+apply.
6. Perf guard: clone+apply budget ~2s for typical parts; skip with an explicit
   `skipped: budget` marker for docs above a size threshold (no silent skips).
7. Tests: side-effect-free proof; each check class on fixtures (dangling ref, fillet
   too big, hole through nothing, downstream break); override event emission; MCP
   tool smoke.
8. MCP freshness (server instructions: preflight before big edits) + `graphify update .`.
