## Context

Pillar 20 Part II (docs/ADVISOR_ARCHITECTURE.md §2.14). Hunter directive: agents
manage multiple open documents at once so an assembly's parts are built in parallel
by sub-agents and the user can watch all of them live. Needs: a doc ownership
registry (write leases), buildgraph-driven fan-out (T-W15 ready_nodes), and per-doc
event streams the GUI can subscribe to (T-W17 renders the viewports).

## Files / areas touched

- `services/agent/workspace.py` — new: lease registry (write/read leases, expiry on
  handoff/death/revocation), per-doc event stream (JSONL under the run dir; events:
  opened, op_applied, rebuilt, rendered, advisory, lease_change)
- mutation guard seam — MCP dispatch layer (tool_registry guard) rejects mutating
  calls on a doc whose write lease belongs to another agent, naming the owner
- fan-out executor — consume T-W15 `ready_nodes()`: part nodes spawn modeling
  sub-agents via delegation (T-W14 if merged; else direct role spawn with a TODO
  seam), one doc per part, assembly doc single-writer
- `services/mcp/` — `workspace_status(run_id)` tool (docs, owners, node statuses,
  latest render per doc)
- tests: `services/agent/test_workspace.py`

## Steps

1. Read docs §2.14 + contract §12 (lease field on delegation nodes) + §13.
2. Lease registry: acquire/release/steal rules (steal only via harness on owner
   death/revocation — never model-initiated); read leases unlimited; write lease
   single-holder; all transitions ledger events.
3. Mutation guard: hook the existing `_guard()` dispatch path in tool_registry —
   doc_id-bearing mutating calls check the lease; rejection message names owner +
   how to request handoff (this must not slow read tools; benchmark the hook).
4. Fan-out: for each ready part node, spawn the modeler with a brief built from the
   buildgraph node + ledger slice; join at mate/verify nodes; failed part blocks
   only its dependents (T-W15 policy).
5. Per-doc event streams: append-only, replayable, include render artifact paths
   (contact sheets already produced by the loop) so the GUI can show live previews
   without engine coupling.
6. `workspace_status`: one call for the whole picture (GUI poll target until a push
   channel exists).
7. Tests: lease contention (two agents, one doc — second rejected with owner named);
   steal on simulated death; fan-out on a 3-part fixture graph with join; event
   stream replay; guard perf smoke.
8. MCP freshness + `graphify update .`.
