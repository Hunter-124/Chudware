## Context

Hunter directive 2026-07-05: "make the levels of tokenism, parallelization, and sheer
wastefulness adjustable by levels in the settings tabs, with simple/advanced settings
modes for different tiers of users, where the advanced mode actually exposes all of the
options for what kinds of harness options are available."

The machinery already exists as data (contract aicad.advisor/1.4): tier profiles +
deliberation dial (§8, services/agent/tiers.py + tiers.yaml), councils (§19), ponder
delegations (§12), cognition ladder rungs (§22, ladder.py), trigger injection (§20),
delegation depth/fan-out (§12, delegation.py), preflight (§10), overseer audit cadence
(§11), per-role context budgets (role cards). What's missing is USER OWNERSHIP of the
dial from the GUI. Same principle as routing (§14 addendum): shipped values are initial
defaults only; nothing hardcoded outside user-editable config.

DEPENDS ON T-G22 (settings consolidation) — build inside its reorganized settings
structure, do not fork the old modal. T-G22 merges first.

## Definition of done

- [ ] Simple mode: single "AI Effort" level — Eco / Standard / Deliberate / Maximum —
      rendered as a labeled slider/segmented control with a one-line cost/benefit hint
      per level. Each level is a named PRESET mapping onto the full knob set (presets
      live in data, e.g. services/agent/effort_presets.yaml, not code).
- [ ] Advanced mode (toggle within the AI settings area): exposes ALL harness knobs,
      grouped: Deliberation (ladder rungs mandatory/optional/off, council enable + seat
      count, ponder count + budget), Parallelization (delegation depth, worker fan-out,
      multi-doc parallel parts), Safety nets (preflight on/off, overseer audit cadence,
      failure-card attempt budgets), Context (per-tier prompt budget, trigger-injection
      aggressiveness, context-pack verbosity). Every control shows the live resolved
      value and which preset/override supplies it.
- [ ] Per-tier scoping: knobs resolve per model tier (local-24k/local-48k/mid/frontier)
      with the INVERTED dial preserved as the shipped default (local = full machinery,
      frontier = minimal). User overrides stored per tier.
- [ ] Freedom rule: absurd combinations warn (with WHY) but never block or silently
      clamp. Warnings mirror the routing editor's warn-never-block pattern.
- [ ] Persistence: overrides in config.json (or a sibling user yaml) — tiers.py resolves
      shipped defaults + user overrides; the design gym (T-W27) and mission pipeline
      read the SAME resolution path, so gym tuning and user settings are one system.
- [ ] Ledger/inspectability: effective effort profile snapshot recorded as a ledger
      event at mission start (replayable).
- [ ] Tests: preset resolution, override precedence, warn conditions
      (services/agent/test_tiers.py extension or new test file).
- [ ] Headless AI_CAD_SHOT scenarios: simple mode, advanced mode expanded, warning
      state — light + dark, eyeballed.
- [ ] scripts/gate.sh green (issue #16 known failures excepted); `graphify update .`.
