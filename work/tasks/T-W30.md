## REAL-cycle findings (T-W30 finisher fable-ash, 2026-07-05)

All C1 real cells executed genuinely (real model turns, real MCP dispatch, honest
grading); overall pass 0.000 in every cycle — real results, unmassaged. Failure
classes, in the order they were peeled back:

1. **role-card wiring dropped (FIXED)** — node_runner read `node["role"]` but the
   mission compiler stores `inputs.role`; AND the card allowlist was applied with
   `setdefault` on a key context_pack.assemble() always sets (None). Result: no role
   prompt, no tool list in the turn prompt → 100% invented tool names in run 1.
2. **context starvation (FIXED)** — synthesized node requests referenced "the project
   brief" without containing it; the model correctly stalled asking for it. Node
   requests now embed verbatim manifest content (request + deliverable + ACs).
3. **tool-schema blindness (OPEN)** — with real names in the prompt (run 2+) the model
   calls real tools (add_features, fit_calc) but guesses kwargs ("unexpected
   keyword"); the prompt carries tool NAMES only, no schemas. Follow-up: inject
   trimmed schemas per §9.1 tools slot (tiers.trim_tool_schema already exists).
4. **dispatch-coverage gap (OPEN)** — role cards allow run-scoped tools (ledger_get/
   ledger_note, dag_plan, ask_user, delegate, part_search) that the process-wide
   battery/research resolver cannot serve; needs a run-scoped dispatcher bound to
   the mission (ledger handle, run_id, parts hub).
5. **fabricated handoffs (CAUGHT BY DESIGN)** — a DELIVER node invented "a 22%
   improvement"; a VERIFY node handed off PASS verdicts it never measured. The
   honest reviewer gate ignores handoffs; the cells graded FAIL — exactly the
   fabrication class the T-W30 verify-gate fix exists to stop, working.
6. **taxonomy gap (OPEN, minor)** — a mission stalling pre-BUILD classifies as
   incoherent_geometry with empty evidence seqs; a dedicated execution_stall class
   would read better. Lead-owned taxonomy change, not applied here.
